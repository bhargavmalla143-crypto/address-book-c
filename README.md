# Address Book Management System in C

A console-based Address Book application developed using C programming language.

## Features
- Create Contact
- Search Contact
- Edit Contact
- Delete Contact
- List All Contacts
- File Handling using CSV/TXT

## Technologies Used
- C Language
- File Handling
- Structures
- Modular Programming (Header Files)

## How to Run
1. Compile:
   gcc main.c contact.c file.c -o addressbook
2. Run:
   ./addressbook
